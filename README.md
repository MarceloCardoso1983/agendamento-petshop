# 🐶 Sistema de Agendamento PetShop

Projeto desenvolvido para simular um sistema de agendamento de serviços para pet shop.

## 🚀 Funcionalidades

- Cadastro de cliente
- Cadastro de pet
- Agendamento de serviço
- Listagem de agendamentos

## 🛠️ Tecnologias

- HTML
- CSS
- JavaScript

## 📌 Objetivo

Praticar lógica de programação e desenvolvimento web.
